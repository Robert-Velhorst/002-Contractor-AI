# Code of Conduct

## Our commitment
We want everyone who participates in this project to have a respectful, safe, and constructive experience.

## Expected behavior
- Be considerate, patient, and respectful.
- Discuss ideas and work, not personal traits.
- Accept constructive feedback and differing viewpoints.
- Respect privacy. Do not publish another person's private information.

## Unacceptable behavior
Harassment, discrimination, threats, deliberate intimidation, personal attacks, doxxing, sexualized attention, and other conduct that a reasonable person would find harmful are not acceptable.

## Enforcement
Project maintainers may edit or remove contributions and may temporarily or permanently restrict participation when this Code is violated. They will consider the nature and impact of the conduct.

## Reporting
To report a conduct concern privately, use GitHub's [report abuse guidance](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) and choose the Report abuse to GitHub Support option for the relevant profile, repository, issue, pull request, or comment. Do not include personal or sensitive details in a public issue. This route sends the report to GitHub Support; this personal-account repository does not provide a private report channel directly to its maintainers. For security vulnerabilities, use this repository's private vulnerability reporting feature when available.
