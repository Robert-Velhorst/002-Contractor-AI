# Security Policy

## Supported versions

This repository does not promise a support window or guaranteed security fixes for specific releases. Security reports are welcome for the current `main` branch and published releases. Maintainers will assess reports and prioritize fixes as capacity permits; no acknowledgement, remediation, or backport deadline is guaranteed.

## Report a vulnerability

Use **Report a vulnerability** on the repository's [GitHub Security tab](https://github.com/Robert-Velhorst/002-Contractor-AI/security). Private vulnerability reporting is enabled, so the initial report is sent privately rather than posted as a public issue. Include the affected commit or release, impact, reproduction steps, and a safe proof of concept where useful. Do not include real user data, working credentials, or unrelated secrets.

If private reporting is unavailable, open a public issue with only the title **Request private security contact**. Do not include vulnerability details, exploit code, affected user data, or credentials. Do not disclose an unpatched vulnerability through public issues, discussions, or pull requests.

## Coordinated disclosure

Please allow maintainers reasonable time to investigate and coordinate a fix before public disclosure. Acknowledgement, severity assessment, remediation, and disclosure timing depend on impact and maintainer availability; no response-time or remediation-time guarantee is offered.

Security reports are for vulnerabilities in this repository. Use regular issues for non-security bugs and product support.

## Response and disclosure

Reports are reviewed on a best-effort basis. No response or remediation timeframe is guaranteed. Coordinate any public disclosure with the maintainers so users have a reasonable opportunity to receive a fix.
