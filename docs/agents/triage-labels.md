# Triage Labels

Default configuration for future triage workflows, not a verified inventory of
remote labels. Check existing labels before an authorized labeling action; do
not automatically create duplicates or overwrite another vocabulary.

| Skill role | Configured label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Needs evaluation |
| needs-info | needs-info | Needs more information |
| ready-for-agent | ready-for-agent | Specified for agent implementation |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

The repository owner can edit this mapping without reinstalling the skills.
